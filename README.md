# Russian Android Apps — VPN/TUN Exclude List

Список Android-приложений российских сервисов, которые рекомендуется
исключать из VPN/TUN-маршрутизации. 

### Почему нужно исключать?
Российские приложения намеренно могут замедлять скорость, отказываться работать при включенном TUN, причем не всегда уведомляя об этом пользователей. 

### Почему наш список?
Список формируется на основе:

- анализа механизмов VPN/TUN detection;
- динамических исследований Android-приложений;
- публичных технических исследований;
- практических списков split-tunneling;
- проверки актуальных Android package ID.

### Отступление
Цель проекта — предоставить актуальный и пригодный для автоматического
использования список package ID для VPN-клиентов, firewall-приложений
и систем split-tunneling.

Исследования и поддержка списка проводятся
[Tunnel](https://github.com/hussaroff/tunnel), разработчика VPN-клиента
Tunnel, предназначенного для обхода сетевых ограничений, а также для
анонимизации и шифрования сетевого трафика.
